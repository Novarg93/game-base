# Решения v1

- Сохранены World и существующие Phaser-системы. Внешний ID контента отделён от ключа поведения, чтобы новые герои/враги/навыки могли переиспользовать текущие реализации.
- Единственная точка сборки настроек — GameDefinition; специальные таймлайны bosses/ultimate продолжают использовать существующие модули конфигурации. Валидация выполняется перед запуском.
- Default HD остаётся native-представлением с исходными manifest и artwork. Generic renderer обслуживает Primitive и независимые новые packs. Простые замены actor/projectile/Mage VFX доступны поверх HD через customAssets.
- Визуальная геометрия не определяет столкновения. Визуальные модули не обращаются к RNG и не изменяют World.
- Phaser импортируется динамически; Vue-компонент не создаёт вторую Vue root. Каналы событий, URL базы ассетов и адаптер принадлежат экземпляру.
- Cleanup на SHUTDOWN и DESTROY идемпотентен: уничтожение Phaser целиком не обязано вызывать shutdown. ResizeObserver использует setParentSize, поскольку resize предназначен для Scale.NONE.
- Локальные профили разделены по game ID. Результаты клиента не получают финансовой/соревновательной авторитетности.
- Golden fixtures получены из исходного коммита **этого репозитория** ce7ad0f99d777dc88c4205d2159517d6588c818c: 120 секунд seeded-симуляции для Mage и Warrior со всеми пятью навыками ранга III. Хеши состояния совпадают после рефакторинга. Соседний PixelSurvivor не открывался и не изменялся.
- Старые stage-план, отчёты и инструкции по отсутствующим материалам удалены. Runtime asset/frame names сохранены. Новые docs/tests/screenshots больше не игнорируются Git.
- Изменений зависимостей/баланса, генерации artwork, commit/push/deploy нет.
